## 1. 언리얼 엔진 실행 및 프로젝트 생성

언리얼 엔진을 실행하는 방법은 크게 두 가지임.

- **에픽 런처** 에서 원하는 버전을 선택해 실행

- 엔진 설치 폴더의 바이너리에서 직접 실행

  → 여러 버전을 설치해 관리할 때, 버전별 실행/전환이 쉽다는 장점이 있다.
- 실행 파일 속성에서 버전 확인 가능 (원하는 버전이 명확하지 않을 때 유용함)

### 프로젝트 생성 절차

1. `New Project` 선택 → 게임 템플릿 / 블루프린트 기반 / 데스크톱 최적화 옵션 설정
2. 프로젝트 저장 위치 설정 후 새 빈 폴더 생성 
3. 프로젝트 이름 지정 후 생성
4. 새 프로젝트는 기본 컨텐츠 없이 **빈 상태**로 생성됨

## 2. 에디터 기본 인터페이스 및 레이아웃

- 기본 레이아웃 구성: **Actor, Outliner, Contents browser**

- 레이아웃 저장/복원 기능으로 개인별 편집 환경 구성 가능
  - `파일 > 레이아웃 저장` / `불러오기`
- **에디터 언어는 영어 사용 권장** 

-> 1. 대부분 실무에서 영어로 씀
   2. 한국어보다 커뮤니티 문서 검색, 협업, 셰어 환경에 유리하기 때문

## 3. 레벨 작업 및 저장

- 새 레벨 생성 시 **기본 레벨** 선택 권장 (오픈월드 템플릿은 무겁고 초보자에게 불리함)
- 레벨은 기본적으로 `Untitled` / `No Name` 상태로 생성됨
- 작업 전 반드시 `Ctrl + S` 로 레벨 저장(!중요!), 저장 위치와 이름 지정
- 콘텐츠 브라우저에서 레벨 파일 및 프로젝트 폴더 구조 탐색 가능
- 불필요한 자동 생성 파일은 삭제해도 무방 (엔진이 필요시 재생성함)

## 4. 주요 에디터 패널 및 기능

| 에디터 창 | 기능 및 설명 |
|---|---|
| Contents browser | 에셋 관리 및 프로젝트 내 리소스 탐색, 임포트/익스포트 |
| Outliner | 현재 레벨에 배치된 모든 액터 목록 관리, 검색 & 선택 |
| Actor Panel | 큐브, 구, 평면 등 다양한 형태의 액터 배치 |
| Detail panel | 선택한 액터의 속성(위치, 회전, 크기, 머티리얼 등) 상세한 편집 |

### 개념 정리

- **Actor**: 언리얼 월드에 배치 가능한 최소 단위. 유니티의 `게임 오브젝트`와 동일한 개념
- **Static Mesh**: 움직이지 않는 고정 오브젝트 
- 이동 / 회전 / 크기 조절: 각각 `W`, `E`, `R` 단축키
- `End` 키: 액터를 바닥 면에 딱 맞게 자동 배치
- 편집 카메라 조작: **마우스 우클릭 + WASD** 로 자유롭게 이동/회전

## 5. 에디터 단축키 및 편집 팁

| 단축키 | 기능 |
|---|---|
| `Ctrl + S` | 작업 저장(!!!!!빼먹으면 진짜 안됌 수시로 해야댐) |
| `Alt + P` | 현재 레벨 플레이 시작 |
| `Alt + Esc` | 플레이 종료 |
| `Ctrl + D` | 선택한 액터 복제 |
| `F` | 선택한 액터에 카메라 가까이 붙힘 |
| `Shift + 드래그` | 카메라 이동과 동시에 시야도 이동 |
| `W` / `E` / `R` | 이동 / 회전 / 크기 조절 |
| `End` | 선택 액터를 바닥면에 자동으로 정렬|

## 6. 콘텐츠 관리 및 프로젝트 정리

- 엔진 자동 생성 파일/임시 파일은 필요시 삭제 가능 (엔진이 재생성함)
- 여러 프로젝트를 한 PC에 설치 시 하드디스크 용량 관리 중요
- 불필요한 프로젝트 폴더와 캐시 파일은 주기적으로 정리 
- Git 등 버전관리 시 `.gitignore` 로 불필요 파일 제외 가능 

---

## 7. 레벨 생성과 액터 배치

1. 새 레벨 생성 후 저장 
2. 콘텐츠 브라우저 또는 액터 배치 패널에서 기본 큐브를 드래그 앤 드롭으로 배치
3. `W`(이동) / `E`(회전) / `R`(스케일) 단축키로 액터 위치 조정
4. `Ctrl + D` 로 빠르게 복제
5. `Alt + P` 로 즉시 실행해 게임 내 위치와 동작 확인
6. 필요 시 액터 선택 후 `F` 키로 카메라 포커스 이동

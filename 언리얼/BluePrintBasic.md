# [Unreal] 레벨 블루프린트 기초 

> TIL — 2026-08-4

레벨 블루프린트 배웠다. 특정 레벨에만 종속되는 스크립트/비주얼 프로그래밍 공간이라고 보면 됨. 코드 안 쓰고 노드 연결해서 로직 짜는 방식(생소하긴함).

## BeginPlay vs Tick

- `BeginPlay` : 딱 한 번만 실행되는 이벤트. 초기 설정할 때 씀
- `Tick` : 매 프레임마다 반복 실행됨. 계속 업데이트해야 하는 로직에 씀

이 둘이 시작점 역할을 하는 노드라서, 여기서부터 다른 노드들을 연결해나가는 구조.

## Print 노드로 로그 찍기

화면에 로그 메시지 띄우려면 Print 노드 추가하면 됨. 옵션에서

- 메시지 색상
- 지속 시간(얼마나 오래 화면에 떠있을지)

조절 가능. 디버깅할 때 지금 이 흐름이 실행되고 있는지 눈으로 바로 확인할 수 있어서 유용함.

## 노드 다루기

- 노드 연결 / 끊기 자유롭게 가능
- 줌인/줌아웃으로 그래프 전체 보면서 작업
- 원하는 액션 검색해서 노드로 바로 삽입 가능 (검색 방식이랑 노드별 필터링 방식이 좀 다름 — 상황 따라 골라 쓰면 됨)

## 컴파일 & 실행

- `F7` : 컴파일
- `Alt` : 플레이(실행)

변경사항 있으면 노란 경고 뜸 → 컴파일해서 확인하고 → 바로 실행해서 결과 확인. 이 사이클이 빠르게 돌아가서 수정하고 바로 테스트해보기 편함.
